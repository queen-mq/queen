# Contributing to Queen MQ

Thanks for your interest in Queen!

- **Bug reports & feature requests** — open an issue using the [issue templates](https://github.com/queen-mq/queen/issues/new/choose). For bugs, include the server version, how you run it (Docker, Helm, bare binary), and the client/SDK you use.
- **Code contributions** — everything you need to build, run, and test every component (C++ broker, libqueen, SQL schema, dashboard, proxy, and all five client SDKs) is in **[DEVELOPING.md](DEVELOPING.md)**. Start there; the "5-minute developer loop" gets you from clone to a running broker.
- **Pull requests** — target `master`, keep changes focused, and run the test suite of the component you touched (per-component test commands are in DEVELOPING.md).
- **Security issues** — please do **not** open a public issue; see [SECURITY.md](SECURITY.md).
- **Documentation** — user docs live in `docs/` (published at [queenmq.com](https://queenmq.com/)); deep-dive developer docs in `developer/`.
