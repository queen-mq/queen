% Draft by Claude, 2026-10-24. Every command ran on 2.6.0 in Docker: kcat 1.7 against the Kafka
% facade, the S3 sink against a versitygw gateway, the PostgreSQL connectors against postgres:18.
Queen talks to the systems around it from inside the broker: Kafka clients through a Kafka port,
S3 buckets through a sink, PostgreSQL tables through a source and a sink. There is no extra process
to run. Each one is a few settings or one HTTP call, and each one runs on every node of a cluster.
