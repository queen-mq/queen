## Start a broker

One binary serves the HTTP API and the dashboard on one port:

```bash
docker run -p 6632:6632 ghcr.io/queen-mq/queen:2.7.0
```

Open `http://localhost:6632` and watch every step of these pages land in the dashboard.

## Add the client

| Language | Install |
| --- | --- |
| JavaScript | `npm install queen-mq` |
| Python | `pip install queen-mq` |
| Go | `go get github.com/smartpricing/queen/clients/client-go/v2` |
| Rust | `cargo add queen-mq serde_json` and `cargo add tokio --features rt-multi-thread,macros` |
| PHP | `composer require queen-mq/php-client` |
| C++ | Header only: `clients/client-cpp/queen_client.hpp`, with cpp-httplib and nlohmann/json |

No SDK is needed to try anything: the API is JSON over HTTP, and `curl` is a complete client.
