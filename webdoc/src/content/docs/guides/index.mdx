Each guide is one thing to build, with the code, why it holds, and what it does not do.

## Patterns

- [One state machine per entity](/guides/state-machines/): an order that is created, paid,
  shipped, or cancelled by its own timer, run by stateless workers with no locks.
- [Charge a card once](/guides/exactly-once/): make a redelivered message harmless with a marker
  that commits with the ack.
- [Deliver webhooks](/guides/webhooks/): ordered per endpoint, a retry budget, and a dead-letter
  queue for what never succeeds.

## Features

- [Streams](/guides/streams/): windows and aggregates in your own process, with the state in
  Queen and one commit per cycle.
- [Ephemeral queues](/guides/ephemeral/): in-memory queues for request/reply, signals and
  presence, where losing what is in flight is acceptable.

## Integrations

- [Connect Kafka clients](/guides/kafka/): the built-in Kafka wire protocol, and how topics,
  groups and offsets map onto Queen.
- [Laravel](/guides/laravel/): Queen as a Laravel queue connection, with per-entity ordering and an
  optional supervisor.
