An acknowledgement moves a cursor, it does not delete anything. The messages stay until retention
removes them, so the history is still there to be read a second time.

Two operations use that, and they are not interchangeable. A **new group** is pointed at the
beginning with `subscriptionMode('all')`, which is how a consumer that did not exist when the
events happened gets backfilled. The mode applies once, when the cursor is created, so it can
never rewind a group that already exists.

That is what a **seek** is for. It moves an existing group back to a timestamp, and it releases any
live lease, so an in-flight batch is abandoned rather than acknowledged. Here the seek goes
through `admin()`, a method that returns the same `Admin` instance every time, and the timestamp
travels as a string, so it has to be ISO 8601 in UTC and not a `DateTimeImmutable`.

## Run it

Against a broker from [the quickstart](/start/quickstart), from `examples/tutorials/php` with the
PHP client installed:

```bash
QUEEN_URL=http://localhost:6632 php 04-replay.php
```

The program checks its own outcome and exits non-zero if a check fails. Every tutorial in this
section runs in the repository's own suite: `examples/tutorials/run.sh php`.
