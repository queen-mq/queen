The broker is configured entirely through environment variables: 97 of them, listed below with the defaults the code actually applies. Booleans go through one strict parser: an unparseable value is a fatal boot error, while unset and empty both fall back to the default.

**Also read as** is an older name for the same setting: either name configures the same thing, and the row's name wins when both are set.
