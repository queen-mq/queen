# P8: W1 regression + the workloads W2-W6 under faults, graceful restarts,
# membership changes and data.mdb corruption.
#
#   cd /root/jepsen-p8
#   sed '/^# --- 5/,$d' matrix-p8.txt > p8-part1.txt
#   sed -n '/^# --- 5/,$p' matrix-p8.txt > p8-part2.txt
#   RUNS=/root/runs-p8 BIN=/root/bin/queen-6bc22551 ./run-campaign.sh p8-part1.txt
#   RUNS=/root/runs-p8 BIN=/root/bin/queen-membfix ./run-campaign.sh p8-part2.txt
#
# run-campaign.sh = run-matrix.sh (the 5 nodes, the ssh key, --bin,
# --concurrency 2n) plus a 40-minute cap per test and one PROGRESS.txt line
# per test (progress.py: valid?, acked ops, nemesis ops, checker counts).
#
# Every line is one 300 s test. Measured on P6/P7: a 300 s test takes
# 5:50-7:10 of wall time (setup, recovery, final reads, analysis): 6.5 min;
# 7 min for membership and corrupt tests (cycles and rejoins at the end).
# The sections run in priority order: stop after any section and what ran is
# a complete answer for its workloads.
#
# Estimate: 78 tests. Sections: 1 = 8 tests, 0.9 h; 2 = 27 tests, 2.9 h;
# 3 = 21 tests, 2.3 h; 4 = 7 tests, 0.8 h; 5 = 15 tests, 1.7 h.
# Total ~8.6 h wall; 6 VMs (control + 5 nodes) = ~52 VM-hours.
#
# Part 1 (sections 1-4) runs on queen-6bc22551 (raft 6bc22551, the W4 fix).
# Section 5 changes the membership (the membership nemesis, and the corrupt
# nemesis's rejoin remedy): it runs on queen-membfix (raft 38d1ad23, a
# membership change pauses the leader's batcher; on 2b1d5524/6bc22551 every
# change stopped it: "an entry landed at another index than planned; the
# driver stops"), with one part-1 test (W1 kill) repeated on it.
#
# Fault names: kill / pause / partition / clock (Jepsen combined packages),
# bridge, leader-deaf (this suite), restart = graceful SIGTERM -> exit -> start
# (one node or rolling), membership = remove / wipe / rejoin through the admin
# API, corrupt = damage one file of one node, "lz" = --lazyfs (a kill loses
# what was not fsynced). KV workloads (W3, W3b, W3c, W4) run at --rate 100
# (Knossos / Elle analysis), the others at 200.
