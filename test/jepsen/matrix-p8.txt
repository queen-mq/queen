# Every line is one 300 s test (run-matrix.sh adds the 5 nodes, the ssh key,
# --bin and --concurrency 2n). Measured on P6/P7: a 300 s test takes 5:50-7:10
# of wall time (setup, recovery, final reads, analysis); budget 6.5 min.

# a complete answer for its workloads.

# Estimate: 62 runs x 6.5 min = ~6.7 h wall; 6 VMs (control + 5 nodes) =
# ~40 VM-hours. Sections: 1 = 2.8 h, 2 = 0.9 h, 3 = 2.3 h, 4 = 0.8 h.
# W4 (elle) is already invalid without faults (G1c, see the smoke): its fault
# runs show which OTHER anomalies faults add; drop them to save ~0.8 h.
#
# Fault names: kill / pause / partition / clock (Jepsen combined packages),
# bridge, leader-deaf (this suite), restart = graceful SIGTERM -> exit -> start
# (one node or rolling), "lz" = --lazyfs (a kill loses what was not fsynced).
# KV workloads (W3, W3b, W3c, W4) run at --rate 100 (Knossos / Elle analysis),
# the others at 200.
