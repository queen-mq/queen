# The idle-drop subset (2026-11-25, branch partitionrmfix): an idle (group, partition)
# record now leaves the leader's memory when its idle window ends (each shard keeps the
# windows in a wheel of 10 ms slots), and the next append there loads it back from its
# cursor row. The window is shortened to 1 s (QUEEN_CONSUME_IDLE_UNLOAD_S=1, default 600)
# so records leave and come back all through the faults: on pop and ack (queue), in
# transactions that ack (pipeline), retries and dead letters (dlq, dlqops), fired timers
# (timers), filtered groups (filtered), a group moved by a seek (seek), a queue deleted
# and made again (lifecycle), delayed messages (queueopts delayed) and the retention scan
# (retention). Every test here consumes with a group: the KV and read-by-offset workloads
# (claim, txnmix) hold no consume record, so they never drop one (first run: 0 dropped).
# The last two lines run at the default window: it is armed on every caught-up record and
# never ends inside a test. Each broker logs "consume: idle parts unloaded" at most once a
# minute with the count: grep the node logs of a test's store to see that it dropped.
# Five nodes: RUNS=... BIN=... ./run-campaign.sh matrix-idle-drop-2026-11-25.txt
